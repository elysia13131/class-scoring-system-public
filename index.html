About

系统简介

面向军队院校班级管理的综合性信息化平台

数字化赋能班级管理

班级综合评分管理系统是一套专为军队院校班级管理场景设计的综合性信息化平台。 系统以"六维雷达图"评分体系为核心，覆盖学员评价、数据分析、 心理健康、健康管理等全方位班级管理需求。

采用前后端分离架构，前端基于 React 18 + Vite 构建，搭配 Tailwind CSS 实现现代化响应式界面；后端采用 Node.js + Express 框架， 通过 Socket.IO 实现实时数据同步。同时支持 Android 移动端应用， 真正实现"指尖上的班级管理"。

  • 科学的多维度学员综合素质评价体系
  • 自评与他评结合，确保评价客观公正
  • WebSocket 实时同步，数据变更即刻生效
  • 集成 DeepSeek AI 大模型，智能分析学员成长趋势
  • 支持公网云部署和局域网自部署双模式
Features

核心功能模块

全方位覆盖班级管理各个场景

📊

六维评分系统

围绕学习成绩、体能素质、人文素养、遵章守纪、班级贡献、管理能力六大维度，细分 29 项二级指标，支持自评与他评，自动计算综合得分。

⚡

实时数据同步

基于 WebSocket 技术实现评分数据的实时推送。评分提交后即刻同步到所有终端，无需手动刷新页面。

🤖

AI 智能助教

集成 DeepSeek 大语言模型，提供智能对话、个人成长分析、全班分析报告、数据洞察和图表生成等 AI 功能。

🧠

心理驿站

关注学员心理健康，支持互评提名、心情记录、心理预警、社交关系图谱、心理咨询预约和每周心理报告。

🏃

体能健康管理

BMI 指数追踪、体测成绩导入导出、成绩排名、伤病管理，全方位关注学员身体健康状况。

📱

移动端支持

基于 Capacitor 封装为 Android APK，学员可通过手机随时随地进行评分和查看数据，体验流畅。

📈

数据可视化

基于 ECharts 提供雷达图、趋势图、排名图等多种可视化图表，数据变化一目了然。

📋

值班管理

发布值班任务、记录值班历史、统计值班次数，确保班级日常事务公平分配。

🔐

安全管理

多级管理员权限体系，个人密码验证，数据持久化存储，支持备份恢复，确保数据安全。
